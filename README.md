# Kerala Chakkala Service Society (KCS) Website

Official website repository for Kerala Chakkala Service Society, Thiruvananthapuram.

## Overview
This repository contains the web application and presentation for the Kerala Chakkala Service Society (KCS), featuring:
- Society information, objectives, and leadership
- Community activities, programs, and news
- Embedded photo and video gallery
- Contact and membership information

## Quick Start
Open `index.html` (or `KCS_Society_Website_Reset_YouTube153.html`) in any modern web browser.
